Before you start, ask me for any values in square brackets that I haven't filled in. Ask for all of them in one message.

I'm new to [CONCEPT]. Explain it to me as if I'm smart but have no background in it.

1. Start with a one-sentence definition in plain language.
2. Give me one everyday analogy.
3. List the three things I most need to know, in order of importance.
4. End with one question I can answer to check that I understood.

Keep it under 250 words and avoid jargon. If you must use a term, define it.
